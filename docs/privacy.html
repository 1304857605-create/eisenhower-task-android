一句话概括

不收集、不出售、不共享你的待办和课表内容，没有账号体系。 任务、课程与设置默认只保存在手机本地。联网金句和课程提醒都是可选能力， 默认关闭，只在你主动开启时使用对应权限。

一、我们收集哪些信息

不收集个人信息。不收集姓名、手机号、邮箱、身份证号；不收集设备标识符 （IMEI、Android ID、OAID、MAC 地址等）；不收集位置、通讯录、相册、麦克风、摄像头、剪贴板； 不收集任务、课表、备注内容；不要求注册或登录。

应用中没有广告 SDK、统计 SDK 或社交分享 SDK。

唯一可能产生网络请求的功能是「联网更新金句」（默认关闭）。开启后，应用会向今日诗词 API （https://v1.jinrishici.com/all.json）请求一句古诗文，请求不包含任务、课表、账号或身份信息， 但对方服务器会接收到常规网络信息（如 IP 地址）。关闭后应用不会发起网络请求。

二、你的数据存在哪里

存储位置手机本地应用私有目录中的 SharedPreferences（仅本应用可访问）
存储内容待办、课表（课程/教师/地点/节次/周次）、学期与提醒设置
是否上传否。只有“联网更新金句”会请求一段古诗，不包含本地数据
删除方式在应用内删除；或在系统设置中清除应用数据；或卸载应用

卸载或清除应用数据后，本地数据即被删除，且无法恢复。请在卸载或换机前自行导出备份。

三、权限说明

应用声明的 Android 权限都服务于可选功能，不读取通讯录、位置、相册、麦克风、相机或日历：

权限用途是否必须
INTERNET仅用于“联网更新金句”可选
POST_NOTIFICATIONS仅在开启课程提醒后申请可选
RECEIVE_BOOT_COMPLETED重启后恢复课程提醒仅提醒开启时
VIBRATE通知振动提醒仅提醒开启时

应用没有日历读写权限。“加入系统日历”只是打开系统日历的新建事件界面，由你确认保存。

四、第三方组件

应用基于 Flutter 构建，使用以下开源组件，均不含广告、统计或用户画像 SDK：

  • Flutter 引擎、material_ui：界面渲染，不联网；
  • shared_preferences：本地保存任务、课表与设置；
  • file_picker、excel、archive、html：在本机解析导入文件；
  • flutter_local_notifications、timezone、flutter_timezone：本地安排课程提醒；
  • http：仅在开启“联网更新金句”时请求今日诗词 API。

在线金句服务：今日诗词 jinrishici.com。关闭开关后应用不会使用网络。

五、文件导入、导出与日历

  • 课表文件（ICS / Excel / Word / HTML / CSV）只在本机解析，不会上传；
  • 任务导出/导入由你主动触发，数据只进入系统剪贴板或从剪贴板读取；
  • “加入系统日历”通过系统日历的新建事件界面完成，应用不读取日历内容。

六、课程提醒

课程提醒默认关闭。你开启并授权通知后，应用会在本机安排前一天课程汇总（可选时间）和课前 10/5 分钟提醒。 提醒内容只包含课程名、时间、地点和教师，不上传服务器。你可以随时关闭，关闭后会取消所有本地通知。

七、未成年人保护

应用不收集任何个人信息，不设账号、不做广告、不含内购，未成年人可在监护人指导下使用。

八、政策更新

若未来功能变化涉及数据处理方式，我们会在发布前更新本政策、修改生效日期，并在应用的「关于」页与仓库中同步。
