四象限清单 · 隐私政策

Quadrant List · 生效日期 2026-11-22

本政策说明「四象限清单」Android 应用如何处理你的信息。内容适用于本应用的官方构建版本；任何人基于本项目源代码自行编译、修改或分发的版本，由该分发者自行负责其隐私实践。

一、我们收集哪些信息

没有。具体而言：

  • 不收集姓名、手机号、邮箱、身份证号等身份信息；
  • 不收集设备标识符（IMEI、Android ID、OAID、MAC 地址等）；
  • 不收集位置、通讯录、相册、麦克风、摄像头、剪贴板等任何系统数据；
  • 不收集应用使用行为、页面停留、点击等统计埋点；
  • 不收集崩溃日志或诊断信息，也没有接入任何第三方崩溃上报服务；
  • 不要求注册、登录，不建立任何账号。

应用中没有广告 SDK、统计 SDK、推送 SDK 或社交分享 SDK。

二、你的数据存在哪里

存储位置手机本地应用私有目录中的 SharedPreferences（仅本应用可访问）
存储内容你创建的待办：标题、备注、所属象限、截止日期、完成状态
是否上传否。应用不声明 INTERNET 权限，无法发起网络请求
保存期限直到你删除对应待办、清除应用数据或卸载应用
删除方式删除单条待办；或在系统设置中清除应用数据；或直接卸载应用

卸载应用或清除应用数据后，本地待办数据即被删除，且无法恢复。请在卸载或换机前自行导出备份。

三、权限说明

本应用的 AndroidManifest.xml 不声明任何 Android 权限，包括不声明网络权限。因此：

  • 应用无法读取你的通讯录、短信、位置、相册、摄像头、麦克风；
  • 应用无法访问网络，也无法在后台联网；
  • 应用无法读取其他应用的数据。

你在系统「应用信息 → 权限」中看不到本应用申请的任何权限，这是设计结果，不是显示错误。

四、第三方组件

本应用除 Flutter 引擎与 Flutter 官方组件外，没有引入其他第三方依赖。

Flutter 引擎Google 开源的跨平台 UI 框架，用于界面渲染与应用运行。本项目未集成 Firebase 或其他 Google 数据服务，不涉及数据传输。
material_uiFlutter 官方 Material UI 包，提供 Material 3 界面组件。仅本地代码，不联网。
shared_preferencesFlutter 官方插件，用于在本地读写少量键值数据（待办 JSON）。仅写入本地文件，不联网。

上述组件均不用于广告、统计或用户画像。应用首次启动时会展示隐私政策摘要，用户同意后方可继续使用。

五、导出与导入

  • 导出：由你主动在设置页触发，应用将待办生成为 JSON 文本并复制到系统剪贴板。数据只进入剪贴板，不离开设备，也不会上传到任何服务器。
  • 导入：由你主动粘贴 JSON 文本，应用在本地解析并写入存储。

提示：剪贴板内容可能被设备上其他应用读取。导出后建议尽快粘贴到可信位置保存，并及时清除剪贴板内容。

应用中不存在云备份、云同步或账号同步功能，也不存在「自动上传」路径。

六、未成年人保护

本应用不收集任何个人信息，不设账号、不做广告、不含内购，因此对未成年人不存在针对性数据收集。未满 14 周岁的未成年人建议在监护人指导下使用，并由监护人协助完成数据备份等操作。若监护人对本政策有疑问，可通过下方邮箱联系开发者。

七、本政策不涉及的情形

  • 本应用不含广告，因此不存在广告个性化推荐与广告标识符使用；
  • 本应用不做统计分析，因此不存在使用行为画像；
  • 本应用不含内购与支付，因此不处理任何支付信息；
  • 本应用不提供账号，因此不存在账号数据、注销流程与密码保管问题。

附：常见问题

应用需要联网吗？

不需要。应用没有网络权限，首次打开也无需联网。

会收集我的手机号或设备信息吗？

不会。应用没有采集入口，也没有联网能力。

卸载后数据还在吗？

不在。数据保存在应用私有目录，卸载即删除。请在卸载前导出 JSON 备份。

换手机怎么迁移？

在旧手机导出 JSON（复制到剪贴板）并保存，在新手机安装后粘贴导入。应用不提供云同步。

应用会推送提醒吗？

不会。1.0.0 没有通知与提醒功能，也不申请通知权限。
