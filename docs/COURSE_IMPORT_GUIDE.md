# 课表导入指南（1.1.0）

> 目标：把学校教务系统里的课表导入 App，不上传文件、不保存学校账号。

## 1. 支持的格式

| 格式 | 支持情况 | 建议 |
| --- | --- | --- |
| `.ics` 日历文件 | ✅ | 最推荐，结构最稳定；可从教务系统导出或从手机日历导出 |
| `.xlsx` / `.xls` | ✅ | 推荐；支持“课程名称/星期/开始节次/结束节次/周次/地点/教师”标准列，或“周几 × 节次”的表格 |
| `.csv` | ✅ | 与 Excel 相同 |
| `.docx` | ✅ | 支持 Word 表格；合并单元格复杂时需人工核对 |
| `.html` / `.htm` | ✅ | 教务系统课表页面“另存为网页”后导入 |
| `.pdf` | ❌ 当前版本不支持 | 建议从系统导出 Excel/HTML/ICS，或手动录入；PDF 解析在后续版本 |
| `.doc` 旧格式 | ❌ | 请另存为 `.docx` |

## 2. 从教务系统拿到文件

不同学校系统不同，但常见思路：

1. **找导出按钮**：课表页面常有“导出 / 打印 / 下载 / 导出 Excel / 导出日历”。
2. **打印成 PDF 不行时**：用浏览器“打印 → 另存为 PDF”只能得到 PDF；请优先找 Excel/HTML 导出。
3. **网页另存**：在课表页面按 `Ctrl+S`（手机浏览器可用“保存网页”），保存为 `.html` 后导入。
4. **复制表格**：把课表表格复制到 Excel，整理成标准列后保存为 `.xlsx` 或 `.csv`。
5. **手机日历导出**：如果教务系统支持“添加到日历”，可在系统日历中把课程导出为 `.ics` 再导入。

## 3. 标准列格式（最稳）

Excel/CSV 第一行写表头，至少包含：

```text
课程名称,星期,开始节次,结束节次,周次,教师,地点
高等数学,周一,1,2,1-16周,李老师,教1-201
大学英语,周三,3,4,1-8周,Amy,外语楼302
```

- 星期支持“周一/星期一/一/Mon”；
- 周次支持 `1-16周`、`1-8周(单)`、`1,3,5-8周`；
- 节次支持 `1-2节`、`第1-2节`；
- 表头也支持英文 `course, weekday, start, end, weeks, teacher, location`。

## 4. 周几 × 节次表格

如果学校导出的是“左边节次、上边星期”的表格，直接导入即可。App 会识别表格结构，按单元格中的“课程名 / 教师 / 地点 / 周次”拆分，导入前预览确认。

## 5. 广东高校适配现状

- 当前版本是**通用解析**，不绑定具体学校；正方、强智、青果等系统只要导出的文件是上述格式即可尝试。
- 各校导出按钮、表头命名差异很大，**需要真实样例才能针对性适配**。如果你愿意提供：
  - 学校名 + 教务系统名；
  - 一份脱敏后的课表文件（PDF/Word/Excel/HTML 均可，删掉姓名学号）；
  
  可以继续做该校的专用适配。
- 参考“超级课程表”的账号自动导入需要联网、保存学生账号、后端爬虫/接口适配，且各校不同；这会破坏“数据默认本地”的定位，需要单独做后端与 APP 备案，暂不在 1.1.0 范围。

## 6. 导入后检查

导入不是 100% 准确，请核对：

- 课程是否都在正确的星期；
- 节次是否连续正确；
- 周次是否包含单双周；
- 地点/教师是否错位；
- 学期设置里的“第 1 周周一”是否正确（设置 → 课表 → 学期设置）。

## 7. 隐私

导入的课表文件只在本机内存中解析，不写入临时文件、不上传；解析后的课程保存在本地 `SharedPreferences`。
