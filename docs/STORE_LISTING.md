## 2. 应用简介（可直接复制）

**完整简介：**

> 「四象限清单」把待办按“重要 / 紧急”两个维度分成四格：重要且紧急、重要不紧急、紧急不重要、不重要不紧急。打开首页就能一屏看清所有任务，点卡片进入对应象限；长按任务卡片拖到别的象限，就能快速重新分类。
>
> 支持新建、编辑、删除、勾选完成，可设置截止日期与备注，可显示或隐藏已完成任务并一键清除已完成。首页还有一条公版古诗文“每日一句”，可以在设置中关闭。
>
> 新增课表功能：支持导入 ICS、Excel、CSV、Word、HTML 课表，按周/按天查看，左右滑动切换；可选开启前一天课程汇总和课前 10/5 分钟提醒。课程可以一键加入系统日历。
>
> 任务和课表数据只保存在手机本地，任务支持 JSON 导出到剪贴板备份。应用无广告、无账号、无内购、无统计；通知和网络权限只在用户主动开启“课程提醒”或“联网金句”时使用。

**一句话简介备选（均 ≤34 字符、陈述句、无句末标点）：**
- 无广告的四象限待办与课表，数据在本地
- 用四象限整理待办，用课表安排一周
- 极简待办 + 课表，无广告、可离线

**关键词（按后台标签/搜索词字段填写，避免堆砌）：**
四象限、待办、清单、课表、课程表、日程、时间管理、效率、极简、无广告

**版本更新说明（v1.1.0）：**

> 新增课表：导入 ICS/Excel/CSV/Word/HTML，周/日视图滑动切换，可选课程提醒与加入系统日历；新增每日一句（304 条公版古诗文，可关闭）。权限改为按需开启：通知只用于课程提醒，网络只用于可选的联网金句。

## 5. 隐私合规表单填写建议

| 问题 | 填写 |
| --- | --- |
| 是否收集个人信息 | 否（任务、课表、账号信息都不收集） |
| 是否申请权限 | 是，但均为可选功能：`INTERNET`（联网金句）、`POST_NOTIFICATIONS`（课程提醒）、`RECEIVE_BOOT_COMPLETED`（重启恢复提醒）、`VIBRATE`；不读取通讯录/位置/相册/相机/日历 |
| 是否接入第三方 SDK | Flutter 官方组件 + 文件导入/通知/时区/网络开源库；无广告/统计 SDK；在线金句请求今日诗词 API |
| 数据存储位置 | 应用私有目录（SharedPreferences），卸载即删除 |
| 是否联网 | 可选：仅“联网更新金句”开启时请求今日诗词 API，可关闭 |
| 是否含广告 | 否 |
| 是否含内购 | 否 |
| 未成年人 | 3+，无收集、无付费、无广告 |
| 隐私政策 | 公网 URL + 应用内「隐私政策」页 + 首次启动同意弹窗，三者内容一致 |

> 注意：隐私政策里的开发者名称/联系方式需要与实际提交主体一致。若更换为企业主体，请同步修改 `PRIVACY.md`、`docs/privacy.html` 与应用内 `lib/screens/privacy_screen.dart`。

## 7. 不可使用的表述

避免“最好用”“第一”“必备”“100% 安全”“永久免费”等极限词或绝对化承诺。本项目可以如实描述“无广告、不收集任务数据、通知和网络均可选”，但**不要再写“零权限、不联网、纯本地”**——1.1.0 的在线金句和课程提醒会使用可选权限；准确表述是“权限可选、默认离线”。

> 如果希望提交完全零权限版本，可继续使用 v1.0.0 的 APK；v1.1.0 含可选联网与通知能力。
