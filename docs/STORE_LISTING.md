## 2. 应用简介（可直接复制）

**完整简介：**

> 「四象限清单」把待办按“重要 / 紧急”两个维度分成四格：重要且紧急、重要不紧急、紧急不重要、不重要不紧急。打开首页就能一屏看清所有任务，点卡片进入对应象限；长按任务卡片拖到别的象限，就能快速重新分类。
>
> 支持新建、编辑、删除、勾选完成，可设置截止日期与备注，可显示或隐藏已完成任务并一键清除已完成。深色模式可跟随系统或手动切换。
>
> 数据只保存在手机本地，设置页支持 JSON 导出到剪贴板与粘贴导入，方便换机备份。应用无广告、无账号、无内购、无统计，AndroidManifest 不声明任何权限（含网络权限），不需要登录，打开就能用。

**一句话简介备选（均 ≤34 字符、陈述句、无句末标点）：**
- 无广告的四象限待办清单，零权限、纯本地
- 用四象限整理待办，数据只存在手机里
- 极简四象限清单，无广告、不联网、零权限

**关键词（按后台标签/搜索词字段填写，避免堆砌）：**
四象限、待办、清单、日程、时间管理、效率、极简、无广告、艾森豪威尔矩阵

**版本更新说明（v1.0.0）：**

> 首个版本：四象限首页、待办新建/编辑/删除/完成、长按拖动换象限、截止日期、深色模式、JSON 导出导入、隐私政策确认。无广告、零权限、纯本地。
