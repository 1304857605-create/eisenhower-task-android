# 小米应用商店上架 · 最短路径

> 详细依据见 [STORE_XIAOMI.md](STORE_XIAOMI.md)，逐项打勾见 [PUBLISHING_CHECKLIST.md](PUBLISHING_CHECKLIST.md)，文案与素材见 [STORE_LISTING.md](STORE_LISTING.md)。

## 先看清一件事

**小米应用商店目前不接受个人开发者账号发布 App。** 必须使用企业 / 政府事业单位 / 其他组织主体（2024 年起的规则）。

所以实际路径只有三条：

1. **注册一家公司**（最稳，长期做选这条）；
2. **用个体工商户**尝试按企业类型注册（是否受理需先问小米客服）；
3. **找已有企业合作**，以对方为主体上架，签软著授权/委托开发协议（最快，但权属要写清）。

如果暂时没有主体，可以先用 GitHub Releases / 酷安等渠道分发；小米商店等主体就绪后再上。

## 有主体后的 8 步

### 1. 注册小米开发者账号
- 地址：<https://dev.mi.com>
- 类型：企业 / 组织
- 材料：营业执照、法人身份信息、法人认证或对公打款
- 费用：0 元；审核约 1～3 个工作日

### 2. 申请软著（必须已下证才能提审）
- 平台：中国版权保护中心 <https://www.ccopyright.com.cn>
- 软件名称：**四象限清单**（与 App 主标题一致）
- 材料：申请表、源代码（前后各 30 页，共 60 页）、用户手册/设计说明、身份/营业执照
- 官费：0 元；审查约 60 日内
- 著作权人：必须是开发者主体；如果是个人软著，需要给企业出具授权

### 5. 在小米后台创建应用
填写：
- 应用名称：四象限清单
- 包名：`cn.sifen.quadrant`（上架后不可改）
- 分类：实用工具 / 效率
- 年龄：3+
- 一句话简介：无广告的四象限待办清单，零权限、纯本地
- 上传 APK、图标、5 张截图、完整简介
- 隐私政策 URL
- 软著证书
- 版权/资质信息

### 6. APP 备案
本项目是纯本地单机应用：
- 在后台选择「**无需备案（单机应用）**」
- 下载/签署《单机承诺函》并上传
- **不需要买服务器、域名，也不需要做 ICP 备案**

如果以后加入联网功能，就必须走工信部 APP 备案（管局约 20 个工作日）。

### 7. 提交审核
- 官方审核时效约 1～3 个工作日
- 常见驳回：资质/软著不一致、隐私政策打不开、截图尺寸不符、功能过于简单/同质化
- 本项目已避开：无广告、零权限、隐私弹窗齐全、1080×1920 截图、完整功能闭环
- 如果被判“功能简单”，在简介和截图中强调：四象限矩阵 + 长按拖拽换象限 + 零权限纯本地

### 8. 上架后更新
- 每次更新必须使用同一张签名证书
- 修改 `pubspec.yaml` 的 `version`（例如 `1.0.1+2`），重新构建并上传
- 不要换包名、不要换签名；否则无法覆盖安装
