## 阶段 0 · 决策与主体资格（最先做，决定项目能否上架）

> **结论先行：小米应用商店当前不接受个人开发者账号上架，必须先有企业/组织主体。**（[个人开发者升级公告](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1259)、[注册标准](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1731)）

- [ ] 🔴 **确认开发者主体类型**：已有公司 / 新办公司 / 个体工商户 / 合作企业（负责人：项目负责人）
  - 已有公司 → 直接进入阶段 1
  - 个体工商户 → **先问小米客服是否按“企业”受理**，再决定是否办照
  - 无公司且不办 → 只能走 GitHub/F-Droid 分发（无商店流量，且侧载需 ADV 验证）
- [ ] 🔴 **注册/登录小米账号并绑定安全邮箱**（负责人：主体管理员；依据：[注册认证指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1145)）
- [ ] 🔴 **完成企业实名认证**：多合一营业执照原件照片；法人认证或对公打款（负责人：法人/财务）
- [ ] 🔴 **等待账号审核 1～3 个工作日**，通过后再创建应用（依据：[注册认证指南](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1145)）
- [ ] 🔴 **确认五处名称一致**：开发者账号企业名 = 应用信息开发者名称 = 软著著作权人（或授权）= APP 备案主体（若备案）= 隐私政策开发者信息
- [ ] 🟡 若为个人软著转企业上架：准备软著授权证明（授权人/被授权人/登记号/软件名称/生效日期/签章），并先问客服个人签字是否接受
- [ ] 🟡 保存主体证照扫描件（营业执照、法人身份证正反面）到安全位置，后续备案/申诉会用

## 阶段 2 · 软件著作权（软著）🔴 硬性

> 官方：自受理日起 **60 日内**审查完成；**官费 0 元**；电子证书。（[办理时限](https://www.ccopyright.com.cn/index.php?optionid=1084)、[停征通告](https://www.ccopyright.com.cn/index.php?optionid=1571)）

### 2.1 申请前

- [ ] 🔴 **确定软著著作权人** = 最终开发者主体（公司名义申请最顺；个人软著需授权给公司，多一道材料）
- [ ] 🔴 **确定软件名称**：全称建议「四象限清单」或「四象限清单软件」，简称「四象限清单」（应用主标题必须能对上全称或简称；依据：[名称基本原则](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1796)）
- [ ] 🔴 **确认一个软著只对应一个应用**（不能一证多用）
- [ ] 🟡 **不要买“包过”软著、不要用 AI 批量生成材料**（2026 年起治理非正常申请；[中国版权保护中心要闻](https://www.ccopyright.com.cn/index.php?optionid=999&method=view&optionid=999&auto_id=1524)）

### 2.2 材料制作

- [ ] 🔴 **源代码鉴别材料**：源程序前 30 页 + 后 30 页，每页 ≥50 行；不足 60 页交全部（依据：[所需文件](https://www.ccopyright.com.cn/index.php?optionid=1080)）
  - 页眉统一写「四象限清单 V1.0」，与申请表版本号一致
  - 按 `.dart` 文件顺序导出，避免空行凑页
- [ ] 🔴 **文档鉴别材料**：用户手册/设计说明前 30 页 + 后 30 页，每页 ≥30 行；页眉同样写软件名称+版本号
- [ ] 🔴 **身份证明**：企业为营业执照副本（统一社会信用代码）；个人为身份证
- [ ] 🟡 软件功能描述：四象限模型、拖动换象限、深色模式、JSON 导出导入、零权限/不联网设计
- [ ] 🟡 开发完成日期、发表状态（若已在 GitHub 公开发布可填“已发表”及首次发表信息）

### 2.3 提交与跟进

- [ ] 🔴 登录 [中国版权保护中心软件登记系统](https://register.ccopyright.com.cn/registration.html#/registerSoft) 注册并**实名认证**
- [ ] 🔴 在线填表：软件全称/简称/版本号、开发方式（单独开发/委托开发）、著作权人、权利范围、软硬件环境、编程语言、源程序量、主要功能与技术特点（依据：[填表说明](https://www.ccopyright.com.cn/index.php?optionid=1081)）
- [ ] 🔴 在线打印申请确认签章页 → 签字/盖章 → 扫描 PDF 上传（不得改格式/比例；依据：[申请须知](https://www.ccopyright.com.cn/index.php?optionid=1057)）
- [ ] 🔴 提交后关注站内信；若补正，**30 日内**提交（逾期视为撤回）
- [ ] 🔴 下证后下载 PDF 电子证书，验签并**多处备份**
- [ ] 🟡 记录：受理号、申请日期、预计下证日期（60 日内）

### 2.4 替代方案（仅在非常急时）

- [ ] ⚪ 评估《APP 电子版权认证证书》（小米三选一认可；[应用资质 FAQ](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2251)）
- [ ] ⚪ 先向小米客服确认：当前是否接受该证书 + 你的主体类型

- [ ] 🔴 图标：后台 512 图标 = APK 桌面图标
- [ ] 🔴 截图：5 张 1080×1920、无重复、无 iOS/其他市场元素、与实际界面一致
- [ ] 🔴 隐私政策 URL 当场能打开；应用内弹窗能弹出、能拒绝、能再查看
- [ ] 🔴 应用安装后无权限、无联网、无崩溃
- [ ] 🔴 软著/承诺函已上传且清晰完整
- [ ] 🔴 签名是 release keystore，且已备份
- [ ] 🔴 一句话简介/介绍/关键词无极限词、无虚假承诺、与功能一致
- [ ] 🔴 测试账号栏写明“无需登录”
- [ ] 🟡 应用大小、启动时间正常；冷启动 >1 秒有反馈

## 驳回应急处理

| 驳回理由 | 先做什么 | 依据 |
| --- | --- | --- |
| 个人开发者不可上架 | 换企业/组织主体，或走合作主体 | [个人开发者升级公告](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1259) |
| 软著未提供/名称不一致 | 下证后再提；改名需变更证明 | [应用资质 FAQ](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=2251) |
| 未备案 | 提交单机承诺函+说明；走单机客服申诉 | [备案信息补充指引](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1775) |
| 隐私政策打不开/无弹窗/无拒绝按钮 | 修 URL、补弹窗、改按钮文案 | [隐私政策不合规指引](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1792) |
| 图标/截图不一致/含 iOS/其他市场 | 重做素材，真机截图 | [审核规范](https://dev.mi.com/docs/appsmarket/auditing&evaluation/auditing_criterion/) |
| 功能过于简单/与已收录类似 | 完善功能闭环、突出差异化、重写介绍与截图 | 审核规范 3.5.2～3.5.5 |
| 名称类别词/同名 | 换更具品牌性的名称（同步软著/备案） | [名称基本原则](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1796) |
| 权限与功能不符 | 保持零权限；核对 manifest | 审核规范 2.3.1 |
| 测试无法通过 | 提供测试说明/视频；真机自测 | [审核常见问题](https://dev.mi.com/xiaomihyperos/documentation/detail?pId=1252) |
