# 每日一句 · 公版古诗文名句离线数据

「四象限清单」App「每日一句」功能的离线数据资源。**纯本地、零联网、零权限**，与 App 的隐私定位一致。

- 数据文件：`quadrant-todo/assets/quotes/quotes.json`
- 当前条数：**304 条**（要求 ≥120，目标 150～365）
- 编码：UTF-8（无 BOM），标准 JSON 数组
- 打包约定：在 `pubspec.yaml` 中注册 `assets/quotes/` 目录即可读取；本目录只提供数据，不含 Dart 代码。

---

## 一、字段说明

JSON 顶层为数组，每个元素为对象，四个字段均为**非空字符串**：

| 字段 | 类型 | 说明 | 示例 |
| --- | --- | --- | --- |
| `text` | string | 完整的诗句/词句/古文名句，8～40 个汉字，含中文标点并以 `。` `？` `！` 结尾；不是半句 | `海内存知己，天涯若比邻。` |
| `author` | string | 作者名；《诗经》《周易》《汉乐府》《越人歌》等佚名作品统一标 `佚名`；《论语》标 `孔子`（`士不可以不弘毅…` 为曾子语，标 `曾子`）；《礼记》标编者 `戴圣` | `王勃` |
| `source` | string | 出处，书名/篇名用《》包裹；词标词牌，文标篇名；个别为「自题联」 | `《送杜少府之任蜀州》` |
| `dynasty` | string | 朝代，取值限定为：`先秦` `春秋` `战国` `汉` `三国` `东晋` `南朝宋` `南朝齐` `南朝梁` `唐` `宋` `元` `明` `清` | `唐` |

完整示例：

```json
{"text":"海内存知己，天涯若比邻。","author":"王勃","source":"《送杜少府之任蜀州》","dynasty":"唐"}
```

客户端读取建议（由代码负责）：

```dart
final raw = await rootBundle.loadString('assets/quotes/quotes.json');
final List<dynamic> quotes = jsonDecode(raw); // 每日一句：按日期取模或随机
```

## 二、数据来源与公版（版权）说明

### 1. 收录范围

只收录**中国古代（先秦至清）传世作品**，按体裁覆盖：

- 诗经、楚辞（离骚、九歌、越人歌）
- 先秦诸子与经典：论语、老子、庄子、孟子、荀子、韩非子、周易、礼记
- 汉魏六朝：汉乐府、曹操、曹植、诸葛亮、陶渊明、王羲之、谢灵运、谢朓、王籍、丘迟、吴均、陶弘景
- 唐诗（为主）、宋词、宋诗、古文名句
- 元曲/元诗、明代诗文、清代诗词对联

### 2. 明确不收录

- ❌ 近现代报纸金句、时评、媒体文案
- ❌ 网络流行语、段子、歌词
- ❌ 当代作者、近现代作者的原创句子（包括仍在著作权保护期内的白话诗、翻译诗）
- ❌ 现代人的注释、译文、赏析、拼音、改写（这些可能另有版权）

本文件只保留**古人原文句子**这一最小事实性内容。

### 3. 公版依据

- 全部作者均为古代作者，卒年均远早于 1926 年（最晚的清代作者：林则徐 1850 年卒、高鼎约 1880 年前后卒、龚自珍 1841 年卒）；
- 按《中华人民共和国著作权法》，自然人作品的财产权保护期为**作者终生加死亡后 50 年**，上述作品早已进入公有领域；《诗经》《楚辞》《论语》《周易》等佚名/集体作品本身即属公版；
- 句子来源于《诗经》《楚辞》《论语》《老子》《庄子》《孟子》《荀子》《韩非子》《周易》《礼记》《乐府诗集》《陶渊明集》《李太白集》《杜工部集》《白氏长庆集》《苏轼诗集》《稼轩长短句》《红楼梦》等传世文献的通行本，属古代文本；
- 本目录数据为手工整理与校对结果，随项目以 GPL-3.0 发布，可自由使用。

## 三、筛选与去重原则

1. `text` 全局不重复；同一首诗只收最完整、最适合独立展示的名句。
2. 句子必须能独立成句、语义完整（8～40 个汉字），不收半句、不收生僻错字版本。
3. 内容取向偏**治愈、开阔、有诗意、有向上力**，适合学生每天看；避免政治敏感、低俗、消极厌世内容。
4. 名句准确性优先于数量：**宁可少收，不要错收**；不确定作者/出处的句子宁可不收（见「存疑与异说」）。
5. 保留原文用字，不作现代化改写（如「知者」「自缘」「兼善天下」）。

## 六、存疑与异说（已按通行本文本收录）

1. **「衣带渐宽终不悔，为伊消得人憔悴。」** 通行归属宋·柳永《蝶恋花》，少数选本作欧阳修。按通行本标柳永，`source` 记《蝶恋花》。
2. **「海纳百川，有容乃大；壁立千仞，无欲则刚。」** 通行作林则徐自题联，严格说不是诗词原文，因此 `author` 标「林则徐」、`source` 标「自题联」。
3. **「不畏浮云遮望眼，自缘身在最高层。」** 采用通行本「自缘」，另有「只缘」异文。
4. **「千丈之堤，以蝼蚁之穴溃。」** 采用《韩非子·喻老》原文，未收后世成语化版本「千里之堤，溃于蚁穴」。
5. **「穷则独善其身，达则兼善天下。」** 用《孟子·尽心上》原文「兼善天下」，未采用流传改写「兼济天下」。
6. **《论语》相关**：保留原文「知者不惑」「知者乐水」的「知者」；「士不可以不弘毅，任重而道远」为曾子语，作者标「曾子」。其余标「孔子」的条目为《论语》中孔子语，该书由弟子及再传弟子辑录。
7. **岳飞《满江红·写怀》** 通行归属岳飞，学界对作者有少数异说，按通行本收录。
8. **颜真卿《劝学》** 二首通行归属颜真卿，亦见于后世选本，按通行选本收录。
9. **《诗经》《周易》《越人歌》等先秦佚名作品**，`author` 统一标「佚名」；**《礼记》** 为西汉戴圣编定，标「戴圣 / 汉」。
10. **李绅《悯农二首》** 按其一、其二分别标注出处。

## 七、后续在线接口接入约定（预留）

若后续为「每日一句」增加在线接口，请遵守以下约定，保证**离线优先、可回退、字段兼容**：

1. **离线优先**：App 启动或进入页面时先读本地 `assets/quotes/quotes.json`；在线请求失败/超时（建议 2 秒）时静默回退本地数据，不阻塞 UI、不弹错误。
2. **字段兼容**：在线返回的每条数据必须保留同名字段 `text`、`author`、`source`、`dynasty`（均为 UTF-8 字符串，含义与本地完全一致）；可附加 `id`、`date`、`tags`、`url` 等扩展字段，客户端应忽略未知字段。
3. **返回结构建议**：

   ```json
   {"version": 1, "updatedAt": "2026-11-23", "quotes": [{"text": "…", "author": "…", "source": "…", "dynasty": "…"}]}
   ```

   直接返回数组也应兼容（与离线文件同构）。
4. **内容合规**：在线内容必须同样是**公版或已授权的中国古代作品**；严禁近现代报纸金句、网络文案、歌词、当代作者原创句；不得出现政治敏感、低俗、消极厌世内容。
5. **校验规则**（发布前在服务端跑，与本地自检一致）：条数 ≥120；四字段非空且为字符串；`text` 8～40 个汉字、不重复、以 `。？！` 结尾；`dynasty` 建议限定在上面的枚举内；文件 UTF-8 无 BOM。
6. **去重与合并**：以 `text` 作为去重主键；本地与在线合并时优先采用在线新增内容，同时保留本地兜底数据；`version` 单调递增，客户端按 `updatedAt` 缓存（如 24 小时刷新一次），刷新失败时继续使用旧数据。
7. **已知在线化注意点**：不要在接口层返回注释、译文、赏析、拼音等可能含现代版权的内容；如确需白话译文，应单独做版权审核，不得混入 `quotes` 数组。
